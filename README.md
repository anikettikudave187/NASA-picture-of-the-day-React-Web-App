# NASA Picture of the Day – React App

This is a beginner-friendly React project that fetches NASA’s Astronomy Picture of the Day (APOD) using NASA's public API.
Users can:

- Select a date
- View NASA’s image, title, and explanation
- See search history and click dates to view previous results again

**Features**
- Fetch NASA APOD using NASA API
- Simple UI with:
- Date picker
- Search button
- Display of image, title, and explanation
- Stores previously searched dates
- Click a past date to reload the picture

**Technologies Used**
- React
- Fetch API
- NASA APOD API

**Project Structure**
src/
│── App.jsx
│── header.jsx
│── picture.jsx
│── datePicker.jsx
│── App.css

**Usage**
1. Select a date
2. Click Search
3. NASA image, title, and explanation will appear
4. All searched dates appear as buttons
5. Click a history button to load that date again
